표준 API 로는 파일을 넣을 문이 없었습니다
온디바이스 엔진(ko-KR)은 설치돼 있는데, 파일을 넣거나 결과를 꺼내는 공식 경로가 모두 막혀 있었습니다
막힘 1
SpeechRecognizer 파일 입력
EXTRA_AUDIO_SOURCE 로 파일을 넘기면 인식기 4종 모두 즉시 거부. logcat 에도 흔적이 없습니다.
ERROR_CLIENT(5) · 7~43ms
막힘 2
앱의 「자동 변환」 설정
켜 두어도 앱이 직접 녹음한 것만 처리합니다. 밖에서 넣은 파일에는 걸리지 않습니다.
막힘 3
공개 인텐트
노출된 액션은 백업·복원·MAIN·VIEW 뿐. 전사를 시작하는 인텐트는 없습니다.
막힘 4
결과 텍스트 파일
전사 결과는 앱 내부 DB 에만 있습니다. 사람이 직접 공유·내보내기를 해야 파일이 생깁니다.
막힘 5
화면에서 글자 긁기
uiautomator 는 보이는 만큼만 덤프합니다. 2분 분량이 44자로 잘렸습니다.
막힘 6
가상 디스플레이로 뒤에서 돌리기
앱 분리와 덤프까지는 됐지만 외부 모니터로 인식돼 팝업이 뜹니다. 보류했습니다.
